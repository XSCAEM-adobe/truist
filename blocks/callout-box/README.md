# callout-box

Custom **callout** block. Purpose: article-callout.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row, 1 cell containing ordinary default content: a heading (H2/H3, e.g. 'The highlights', 'Next steps', 'Question: ...') followed by a bulleted list or paragraphs ('Answer: ...'). Inline links and superscript footnote links are allowed. Default background is light grey; add the 'mist' option for the lavender tint.

## Supported variations

| Variation | Option class |
| --- | --- |
| Mist (lavender background) | `mist` |
