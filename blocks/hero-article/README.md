# hero-article

Custom **hero** block. Purpose: article-header.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 2 rows, 1 column. Row 1: hero image (with alt text). Row 2: H1 title, date-line paragraph ('Money and Mindset | May 2025', bold optional), intro paragraph(s). If the date line is omitted it is built from the Category + Publication Date page metadata. The social share rail is added automatically on article pages; do not author it.

No variations.
