# disclosures-footnotes

Custom **disclosures** block. Purpose: page-footnotes.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per paragraph, 1 cell. Row 1 (optional): general disclaimer paragraph with no marker. Each following row: one footnote paragraph starting with a superscript marker, e.g. superscript '1' then the citation text and link. The block gives each footnote an id from its marker (1 -> disc1, 2 -> disc2, † -> disc0, †† -> disc01) so superscript links in the article body pointing to '#disc1' jump to it. Place the block at the end of the article.
