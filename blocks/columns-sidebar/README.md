# columns-sidebar

Custom **columns** block. Purpose: text-with-aside.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: 1 row x 2 cells. Left cell: body paragraph(s). Right cell: a short label paragraph (e.g. 'Examples of collateral:') followed by a bulleted list - rendered as a dark purple rounded box. Columns stack on mobile. Add more rows for more text/aside pairs.

## Supported variations

No variations.
