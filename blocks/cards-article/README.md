# cards-article

Custom **cards** block. Purpose: related-articles.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: One row per card, 1 cell. Article card: eyebrow paragraph (topic, e.g. 'Outsmarting debt'), H3 title linked to the article (the whole card becomes clickable), description paragraph, meta paragraph 'Article | 03/10/2024'. Closing CTA card: H3 heading + one link on its own line (rendered as a button); a card without eyebrow and meta is styled as the CTA tile. Place the block in a section with Section Metadata style 'light-grey' and an H2 'Related resources' above it.

No variations.
