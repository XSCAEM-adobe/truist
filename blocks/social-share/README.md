# social-share

Custom **social-share** block. Purpose: social-share.

## Authoring (Document Authoring)

Model: `auto-blocked`

Usually authored as default content; the block is constructed automatically. Content: No authored content. Inserted automatically by scripts.js on every page whose metadata Template is 'article' (right after the Hero Article block). Share links (Twitter, Facebook, LinkedIn, copy link) are built from the page URL and title. An empty 'Social Share' block may be authored manually on other pages.

## Supported variations

No variations.
